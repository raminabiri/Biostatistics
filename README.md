# دورهٔ جامع آمار زیستی و پزشکی

### از صفر تا پیشرفته — با SPSS، GraphPad Prism، R، Python و Excel

این دوره آمار را **یک بار به‌صورت مفهومی** آموزش می‌دهد و سپس اجرای **هر مفهوم** را در پنج نرم‌افزار، در پنج مسیر مستقل، نشان می‌دهد. می‌توانید فقط یک نرم‌افزار را دنبال کنید یا همه را.

## سه اصل دوره

1. **از پایه تا پیشرفته:** ۱۳ فاز (۰ تا ۱۲)، ۸۲ ماژول و ۵ پروژهٔ جامع، از «داده چیست؟» تا مدل‌های آمیخته، تحلیل بقا، استنباط علّی و میکروبیوم. نقشهٔ کامل در [SYLLABUS.md](SYLLABUS.md).
2. **هر درس، تمرین و حل کامل:** هر درس نظری و هر مسیر نرم‌افزاری تمرین دارد و حل آن گام‌به‌گام نوشته شده است. حل‌ها پنهان‌اند (روی «حل» کلیک کنید) تا اول خودتان فکر کنید.
3. **پنج مسیر مستقل، یک هستهٔ مشترک:** تمرین‌های عملی در هر پنج نرم‌افزار **یکسان‌اند** و جواب عددی یکسان دارند.

## چطور شروع کنم؟

1. [SYLLABUS.md](SYLLABUS.md) را ببینید و مسیر متناسب با خودتان را انتخاب کنید.
2. نرم‌افزار خود را انتخاب کنید و صفحهٔ مسیرش را باز کنید:

| مسیر | مناسب برای | صفحهٔ مسیر |
|---|---|---|
| SPSS | کار منویی، پژوهش بالینی، بدون کدنویسی | [tracks/spss.md](tracks/spss.md) |
| GraphPad Prism | پژوهش آزمایشگاهی و تجربی، نمودارهای انتشاراتی | [tracks/prism.md](tracks/prism.md) |
| R | تحلیل‌های پیشرفته و تکرارپذیر، آمار تخصصی | [tracks/r.md](tracks/r.md) |
| Python | تحلیل داده، خودکارسازی، یادگیری ماشین، بیوانفورماتیک | [tracks/python.md](tracks/python.md) |
| Excel | شروع بدون نصب نرم‌افزار آماری، دیدن گام‌به‌گام محاسبه، کار روزمرهٔ آزمایشگاه | [tracks/excel.md](tracks/excel.md) |

3. برای هر ماژول: **اول درس‌های نظری** (پوشهٔ `lessons/`) را با تمرین‌هایشان بخوانید، **بعد** پوشهٔ نرم‌افزار خود را، و در پایان `review.md` را.
