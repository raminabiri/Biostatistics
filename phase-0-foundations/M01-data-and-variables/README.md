# ماژول M01 — داده، متغیر و ساختار مجموعه‌داده

**فاز ۰ (پایه)** | پیش‌نیاز: ندارد | زمان تقریبی: ۴ ساعت درس نظری + ۲ تا ۳ ساعت برای هر نرم‌افزار

## چرا این ماژول؟

بیشتر خطاهای جدی در تحلیل آماری **پیش از هر آزمونی** رخ می‌دهد: متغیر کیفی به‌عنوان عدد تحلیل می‌شود، کد `-99` به‌عنوان مقدار واقعی وارد میانگین می‌شود، یا اندازه‌گیری‌های تکراری از یک بیمار مستقل فرض می‌شوند. این ماژول جلوی این خطاها را از همان ابتدا می‌گیرد.

## هدف‌های یادگیری

در پایان این ماژول می‌توانید:

1. مشاهده، واحد تحلیل، متغیر و مقدار را در یک مطالعهٔ زیستی یا پزشکی تشخیص دهید.
2. هر متغیر را از نظر نوع (کیفی/کمّی، گسسته/پیوسته) و مقیاس (اسمی، ترتیبی، فاصله‌ای، نسبی) دسته‌بندی کنید.
3. یک مجموعه‌داده را با اصول «دادهٔ مرتب» طراحی کنید و کدبوک بنویسید.
4. قالب پهن و بلند و دادهٔ مستقل و وابسته را از هم تشخیص دهید.
5. دادهٔ گمشده را درست کدگذاری کنید و دو نوع خطای اندازه‌گیری را بشناسید.
6. همهٔ این‌ها را در نرم‌افزار انتخابی خود (SPSS، Prism، R، Python یا Excel) اجرا کنید.
