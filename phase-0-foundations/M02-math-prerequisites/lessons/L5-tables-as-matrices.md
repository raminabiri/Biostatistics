# درس ۲.۵ — جدول به‌عنوان ماتریس (مقدماتی)

[← درس قبل: ۲.۴](L4-functions-lines-growth.md) | [ماژول](../README.md)

این درس کوتاه است و فقط برای **آشنایی**. در فازهای ۰ تا ۷ به ماتریس نیازی ندارید؛ در رگرسیون چندگانه (M47) و روش‌های چندمتغیره (M75 به بعد) دوباره به آن برمی‌گردیم. اگر عجله دارید، می‌توانید این درس را فعلاً رد کنید.

## ۱. ماتریس یعنی جدول عددی

ماتریس یک جدول مستطیلی از اعداد است. هر مجموعه‌دادهٔ مرتب (درس ۱.۳) که فقط ستون‌های عددی دارد، یک ماتریس است:

```
         سن   وزن   فشار
بیمار ۱ [ 57   72.3   152 ]
بیمار ۲ [ 42   79.8   147 ]
بیمار ۳ [ 40   68.2   130 ]
```

| مفهوم | معنا | در مثال |
|---|---|---|
| **ابعاد** (r × c) | تعداد سطر × تعداد ستون | 3 × 3 |
| **عنصر** aᵢⱼ | عدد سطر i و ستون j | a₂₁ = 42 (سن بیمار ۲) |
| **بردار** | ماتریسی با فقط یک ستون (یا یک سطر) | ستون «فشار» = (152، 147، 130) |

**قرارداد آماری:** ماتریس داده را X می‌نامند، با **n سطر** (مشاهده) و **p ستون** (متغیر): ابعاد n × p.

## ۲. ترانهاده (Transpose)

جای سطرها و ستون‌ها را عوض می‌کند. ماتریس r × c به c × r تبدیل می‌شود. نماد: Xᵀ یا X′.

```
A = [ 1  2  3 ]        Aᵀ = [ 1  4 ]
    [ 4  5  6 ]             [ 2  5 ]
                            [ 3  6 ]
```

## ۳. جمع ماتریس‌ها

دو ماتریس **هم‌اندازه** را خانه‌به‌خانه جمع می‌کنیم. مثال: جدول توافقی «جنس × عارضه» در دو بیمارستان:

```
بیمارستان A     بیمارستان B      جمع
[ 12   8 ]   +  [ 20   5 ]   =  [ 32  13 ]
[  6  14 ]      [ 10  15 ]      [ 16  29 ]
```

## ۴. ضرب ماتریس در بردار: «جمع وزنی»

این تنها عملیات ماتریسی است که باید ایده‌اش را بدانید، چون **قلب رگرسیون** است.

فرض کنید یک «نمرهٔ خطر» ساده این‌طور تعریف شده:

```
نمره = 0.1 × سن + 2 × سیگاری (0/1) + 1 × دیابت (0/1)
```

برای سه بیمار:

```
         سن  سیگاری  دیابت          وزن‌ها            نمره
       [ 60    1      0  ]         [ 0.1 ]        [ 0.1×60 + 2×1 + 1×0 ]   [ 8.0 ]
X  =   [ 45    0      1  ]   ×     [ 2   ]   =    [ 0.1×45 + 2×0 + 1×1 ] = [ 5.5 ]
       [ 70    1      1  ]         [ 1   ]        [ 0.1×70 + 2×1 + 1×1 ]   [ 10.0 ]
```

قاعده: **هر سطر** در بردار وزن‌ها، خانه‌به‌خانه ضرب و سپس جمع می‌شود (Σ wⱼ · xᵢⱼ؛ همان Σ درس ۲.۲). شرط: تعداد ستون‌های ماتریس = طول بردار.

رگرسیون خطی چندگانه (M47) دقیقاً همین است: پیش‌بینی = X × b، که b بردار ضرایب (شیب‌ها) است و نرم‌افزار آن را از داده برآورد می‌کند.

## ۵. جمع‌بندی درس

- ماتریس = جدول عددی r × c؛ aᵢⱼ = عنصر سطر i ستون j.
- ترانهاده: جابه‌جایی سطر و ستون.
- ضرب ماتریس در بردار = جمع وزنی هر سطر؛ پایهٔ رگرسیون.

---

## مثال‌های حل‌شده

**مثال ۱.** فایل `M02_clinic.csv` بدون ستون `id` و `sex` یک ماتریس **24 × 7** است (۲۴ بیمار، ۷ متغیر عددی). عنصر a₃,₁ = سن بیمار ۳ = **40**.

**مثال ۲ — جمع سطرها با ضرب.** جدول ۲×۲ «جنس × عارضه» را در بردار (1، 1) ضرب کنید:

```
[ 32  13 ]   [ 1 ]   [ 32 + 13 ]   [ 45 ]
[ 16  29 ] × [ 1 ] = [ 16 + 29 ] = [ 45 ]
```
حاصل: **جمع هر سطر** (تعداد کل هر جنس). ضرب در بردار «همه یک» یعنی جمع.

## تمرین‌های درس ۲.۵

### سطح ۱ — پایه

**تمرین ۲.۵.۱** — ابعاد این مجموعه‌داده‌ها را به‌صورت ماتریس بنویسید: (الف) `M01_uti.csv` (ب) `M01_crp_wide.csv` بدون ستون `id` (ج) قالب بلند همان داده

<details>
<summary><b>حل</b></summary>

- (الف) **30 × 12**
- (ب) **8 × 3**
- (ج) **24 × 3** (id، day، crp)

</details>

**تمرین ۲.۵.۲** — در ماتریس زیر، a₂₃ و a₃₁ چیست؟ ابعاد ماتریس چیست؟

```
[ 5   9   2 ]
[ 7   1   8 ]
[ 3   6   4 ]
[ 0   2   5 ]
```

<details>
<summary><b>حل</b></summary>

- a₂₃ = سطر ۲، ستون ۳ = **8**
- a₃₁ = سطر ۳، ستون ۱ = **3**
- ابعاد: **4 × 3**

</details>

**تمرین ۲.۵.۳** — ترانهادهٔ این ماتریس را بنویسید:

```
[ 2   0   7   1 ]
[ 4   3   5   9 ]
```

<details>
<summary><b>حل</b></summary>

```
[ 2   4 ]
[ 0   3 ]
[ 7   5 ]
[ 1   9 ]
```
ابعاد از 2 × 4 به **4 × 2** رسید.

</details>

### سطح ۲ — متوسط

**تمرین ۲.۵.۴** — تعداد بیماران با و بدون عفونت پس از جراحی در دو فصل:

```
           عفونت  بدون عفونت                 عفونت  بدون عفونت
پاییز:  مرد  [  6      44  ]      زمستان:  مرد  [  9      41  ]
        زن  [  4      46  ]               زن  [  7      43  ]
```

جدول کل دو فصل را با جمع ماتریس‌ها بنویسید و درصد عفونت را برای هر جنس حساب کنید.

<details>
<summary><b>حل</b></summary>

```
       عفونت  بدون عفونت
مرد  [  15       85   ]
زن  [  11       89   ]
```
- مرد: 15/100 = **۱۵٪**
- زن: 11/100 = **۱۱٪**

</details>

**تمرین ۲.۵.۵** — با وزن‌های نمرهٔ خطر بخش ۴ (0.1، 2، 1)، نمرهٔ این سه بیمار را حساب کنید: (سن ۵۰، غیرسیگاری، بدون دیابت)، (سن ۶۵، سیگاری، دیابتی)، (سن ۳۰، سیگاری، بدون دیابت).

<details>
<summary><b>حل</b></summary>

```
[ 50  0  0 ]   [ 0.1 ]   [ 5.0 + 0 + 0 ]   [  5.0 ]
[ 65  1  1 ] × [ 2   ] = [ 6.5 + 2 + 1 ] = [  9.5 ]
[ 30  1  0 ]   [ 1   ]   [ 3.0 + 2 + 0 ]   [  5.0 ]
```
جالب: بیمار ۱ (مسن‌تر، غیرسیگاری) و بیمار ۳ (جوان، سیگاری) نمرهٔ یکسان دارند: اثر ۲۰ سال سن بیشتر (۲ امتیاز) برابر اثر سیگار است.

</details>

### سطح ۳ — پیشرفته

**تمرین ۲.۵.۶** — جدول توافقی ۲×۲ زیر را در نظر بگیرید:

```
           مقاوم  حساس
بخش A   [  12     28  ]
بخش B   [   6     54  ]
```

(الف) آن را در بردار (1، 1) ضرب کنید؛ حاصل چه چیزی را نشان می‌دهد؟ (ب) ترانهادهٔ جدول را در بردار (1، 1) ضرب کنید؛ حاصل چیست؟ (ج) با این دو حاصل، کل نمونه را حساب کنید.

<details>
<summary><b>حل</b></summary>

- **(الف)** [12 + 28، 6 + 54] = **[40، 60]** ← **جمع سطرها**: تعداد بیماران هر بخش.
- **(ب)** ترانهاده: [[12، 6]، [28، 54]] ← × (1، 1) = [12 + 6، 28 + 54] = **[18، 82]** ← **جمع ستون‌ها**: تعداد مقاوم و حساس.
- **(ج)** 40 + 60 = 18 + 82 = **100**.

این همان «حاشیه‌های» جدول توافقی است که در M07 و M35 برای محاسبهٔ درصدها و آزمون کای‌دو به کار می‌روند.

</details>
