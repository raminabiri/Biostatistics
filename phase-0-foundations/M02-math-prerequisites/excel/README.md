## بخش آموزشی

### توابع ریاضی Excel

| ریاضی | Excel | مثال |
|---|---|---|
| xⁿ | `=x^n` یا `POWER(x,n)` | `=2^5` ← 32 |
| √x | `SQRT(x)` | `=SQRT(81)` ← 9 |
| log₁₀ | `LOG10(x)` | `=LOG10(1000)` ← 3 |
| ln | `LN(x)` | |
| log₂ | `LOG(x,2)` | `=LOG(8,2)` ← 3 |
| eˣ | `EXP(x)` | |
| گردکردن | `ROUND(x,1)` | `=ROUND(25.652,1)` ← 25.7 |
| Σx | `SUM(range)` | |
| x̄ | `AVERAGE(range)` | |
| Σx² | `SUMSQ(range)` | |
| Σ(x − x̄)² | `DEVSQ(range)` | |
| میانگین هندسی | `GEOMEAN(range)` | |
| شمارش با شرط | `COUNTIF(range,">=30")` | |

> **دام:** در Excel، `LOG(x)` بدون آرگومان دوم **پایهٔ ۱۰** است، ولی در R و Python `log()` طبیعی است.

### ستون محاسباتی

1. در اولین خانهٔ خالی کنار داده (مثلاً `J1`) نام ستون را بنویسید: `bmi`.
2. در `J2`: `=D2/(E2/100)^2`
3. روی گوشهٔ پایین‌راست خانه دوبار کلیک کنید (Fill handle) تا فرمول تا آخرین سطر کپی شود.

نشانی‌های نسبی (`D2`) هنگام کپی‌کردن تغییر می‌کنند؛ نشانی‌های مطلق (`$B$1`) ثابت می‌مانند. برای نیمه‌عمر (ع۷)، C₀ و t½ را در خانه‌های جدا با نشانی مطلق نگه دارید.

### حل تمرین‌ها

همهٔ فرمول‌ها در برگهٔ `solutions` و ستون‌های زرد فایل حل آمده‌اند.

<details>
<summary><b>حل ع۱</b></summary>

```
J2:  =D2/(E2/100)^2                 (و پایین بکشید)
=AVERAGE(J2:J25)                    → 29.44
=COUNTIF(J2:J25,">=30")             → 10
```

</details>

<details>
<summary><b>حل ع۲</b></summary>

```
K2:  =G2-F2                          (تغییر mmHg)
L2:  =K2/F2*100                      (درصد تغییر)
=AVERAGE(K2:K25)                     → -14.96
=AVERAGE(L2:L25)                     → -10.01
=COUNTIF(K2:K25,"<=-10")             → 17
```

</details>

<details>
<summary><b>حل ع۳</b></summary>

```
M2:  =H2/18
=AVERAGE(H2:H25)    → 151.42
=AVERAGE(M2:M25)    → 8.41
```

</details>

<details>
<summary><b>حل ع۴</b></summary>

```
N2:  =LOG10(I2)
=AVERAGE(I2:I25)          → 207.71
=MEDIAN(I2:I25)           → 208.5
=AVERAGE(N2:N25)          → 2.2717
=10^AVERAGE(N2:N25)       → 186.93
=GEOMEAN(I2:I25)          → 186.93   (همان، با یک تابع)
```

</details>

<details>
<summary><b>حل ع۵</b></summary>

```
=COUNT(C2:C25)            → 24
=SUM(C2:C25)              → 1401
=AVERAGE(C2:C25)          → 58.375
=SUMSQ(C2:C25)            → 84759
=DEVSQ(C2:C25)            → 2975.625
```
برای دیدن «Σ چطور کار می‌کند»، در فایل حل دو ستون کمکی هم ساخته شده: `O2: =C2^2` و `P2: =(C2-AVERAGE($C$2:$C$25))^2`؛ جمع آن‌ها همان جواب‌ها را می‌دهد. علامت `$` میانگین را هنگام کپی‌کردن ثابت نگه می‌دارد.

</details>

<details>
<summary><b>حل ع۶</b></summary>

برگهٔ `genes`:
```
D2:  =C2/B2              (fold change)
E2:  =LOG(D2,2)          (log2FC)
=COUNTIF(E2:E13,">=1")   → 6
=COUNTIF(E2:E13,"<=-1")  → 1
```
جمع: **7**. برای دیدن ژن‌ها: `Data > Sort` بر اساس ستون E؛ یا `Home > Conditional Formatting > Color Scales` روی ستون E (یک نقشهٔ حرارتی ساده!).

</details>

<details>
<summary><b>حل ع۷</b></summary>

برگهٔ `pk`: `B1` = 100 (C₀)، `B2` = 4 (t½)، زمان‌ها در `A5:A17`.
```
B5:  =$B$1*0.5^(A5/$B$2)       (و پایین بکشید)
```
اولین زمان زیر ۱۰: با نگاه به جدول ← **14**؛ یا با فرمول:
```
=INDEX(A5:A17, MATCH(TRUE, INDEX(B5:B17<10,0), 0))   → 14
=B2*LOG(10,2)                                         → 13.29
```
نمودار: جدول را انتخاب کنید ← `Insert > Scatter` ← روی محور Y راست‌کلیک ← `Format Axis` ← **Logarithmic scale** ← منحنی خط راست می‌شود.

</details>
