# کدبوک داده‌های ماژول M02

## فایل `M02_clinic.csv`

**مطالعه:** ۲۴ بیمار مبتلا به دیابت نوع ۲ و پرفشاری خون در یک درمانگاه داخلی؛ فشار خون در شروع و هفتهٔ ۱۲ درمان. **واحد تحلیل:** بیمار. داده‌ها ساختگی‌اند.

| متغیر | شرح | واحد | کدها | مقیاس |
|---|---|---|---|---|
| `id` | شناسهٔ بیمار | — | 1 تا 24 | شناسه |
| `sex` | جنس | — | 1 = زن، 2 = مرد | اسمی |
| `age` | سن | سال | | نسبی |
| `weight_kg` | وزن | کیلوگرم | | نسبی |
| `height_cm` | قد | سانتی‌متر | | نسبی |
| `sbp_0` | فشار خون سیستولی در شروع | mmHg | | نسبی |
| `sbp_12` | فشار خون سیستولی در هفتهٔ ۱۲ | mmHg | | نسبی |
| `glucose_mgdl` | قند خون ناشتا | mg/dL | | نسبی |
| `tg_mgdl` | تری‌گلیسرید ناشتا | mg/dL | | نسبی (توزیع چوله) |

گمشده ندارد.

## فایل `M02_genes.csv`

**آزمایش:** بیان ۱۲ ژن (شمار خوانش نرمال‌شده) در سلول‌های کنترل و سلول‌های تیمارشده با یک محرک التهابی. هر عدد میانگین سه تکرار زیستی است. داده‌ها ساختگی‌اند.

| متغیر | شرح |
|---|---|
| `gene` | نام ژن |
| `control` | بیان در گروه کنترل (واحد دلخواه) |
| `treated` | بیان در گروه تیمار (واحد دلخواه) |
