### R به‌عنوان ماشین‌حساب

```r
2 + 3 * 4^2        # 50  (ترتیب عملیات مثل ریاضی)
sqrt(81)           # 9
81^0.5             # 9
log10(1000)        # 3
log2(8)            # 3
log(exp(1))        # 1   ← log() در R یعنی ln (لگاریتم طبیعی)!

10^2.5             # 316.2
round(25.652, 1)   # 25.7
signif(0.0004567, 2)   # 0.00046  (ارقام بامعنا)

```

### محاسبه روی ستون‌ها («برداری»)

در R هر عملیات روی یک ستون، **روی همهٔ سطرها هم‌زمان** انجام می‌شود؛ حلقه لازم نیست:

```r
d <- read.csv("../data/M02_clinic.csv")
d$bmi <- d$weight_kg / (d$height_cm / 100)^2    # ستون جدید برای همهٔ ۲۴ بیمار
```

| نماد ریاضی | R |
|---|---|
| Σx | `sum(x)` |
| x̄ | `mean(x)` |
| Σx² | `sum(x^2)` |
| (Σx)² | `sum(x)^2` |
| Σ(x − x̄)² | `sum((x - mean(x))^2)` |
| n | `length(x)` |
| تعداد شرط درست | `sum(x >= 30)` (TRUE = 1، FALSE = 0) |
| میانگین هندسی | `10^mean(log10(x))` یا `exp(mean(log(x)))` |

### ساختن دنبالهٔ عددی

```r
seq(0, 24, by = 2)     # 0 2 4 ... 24
t <- seq(0, 24, by = 2)
100 * 0.5^(t / 4)      # غلظت در همهٔ زمان‌ها
```

## تمرین‌های عملی (ع۱ تا ع۷)

این تمرین‌ها در هر پنج مسیر **یکسان‌اند** و جواب عددی یکسان دارند. داده: `data/M02_clinic.csv` و `data/M02_genes.csv`.

| شماره | سطح | تمرین | مفهوم (درس) |
|---|---|---|---|
| ع۱ | ۱ | متغیر جدید **BMI** = وزن ÷ (قد به متر)² بسازید. میانگین BMI چیست؟ چند بیمار BMI ≥ ۳۰ دارند؟ | ترتیب عملیات (۲.۲) |
| ع۲ | ۱ | تغییر فشار (sbp_12 − sbp_0) و **درصد تغییر** را بسازید. میانگین هر دو؟ چند بیمار دست‌کم ۱۰ mmHg کاهش داشتند؟ | تغییر مطلق و نسبی (۲.۱) |
| ع۳ | ۱ | قند خون را از mg/dL به mmol/L تبدیل کنید (÷ ۱۸). میانگین در هر دو واحد؟ | تبدیل واحد (۲.۱) |
| ع۴ | ۲ | log₁₀ تری‌گلیسرید را بسازید. میانگین حسابی، میانه، میانگین log₁₀ و **میانگین هندسی** TG را گزارش کنید. | لگاریتم (۲.۳) |

### حل تمرین‌ها

کد کامل همهٔ تمرین‌ها: [`M02_solutions.R`](M02_solutions.R)

<details>
<summary><b>حل ع۱</b></summary>

```r
d$bmi <- d$weight_kg / (d$height_cm / 100)^2
round(mean(d$bmi), 2)    # 29.44
sum(d$bmi >= 30)         # 10
```
`d$bmi >= 30` برای هر بیمار TRUE یا FALSE می‌دهد و `sum()` تعداد TRUE ها را می‌شمارد.

</details>

<details>
<summary><b>حل ع۲</b></summary>

```r
d$sbp_change <- d$sbp_12 - d$sbp_0
d$sbp_pct    <- d$sbp_change / d$sbp_0 * 100
round(mean(d$sbp_change), 2)   # -14.96
round(mean(d$sbp_pct), 2)      # -10.01
sum(d$sbp_change <= -10)       # 17
```
توجه: «میانگین درصد تغییر» (−10.01٪) با «درصد تغییر میانگین‌ها» ((135.62 − 150.58)/150.58 = −9.93٪) کمی فرق دارد؛ اولی میانگین تغییر افراد است.

</details>

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| میانگین هندسی عجیب | `log()` به‌جای `log10()` و سپس `10^` | یا `log10` + `10^`، یا `log` + `exp`؛ این دو را با هم مخلوط نکنید |
| BMI حدود ۰٫۰۰۳ | پرانتز جا افتاده: `weight / height/100^2` | `weight / (height/100)^2` |
| `NaN` در log | مقدار صفر یا منفی | درس ۲.۳، تمرین ۲.۳.۱۳ |
