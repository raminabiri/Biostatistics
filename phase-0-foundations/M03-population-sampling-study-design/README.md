# ماژول M03 — جامعه، نمونه و طرح مطالعه

**فاز ۰ (پایه)** | پیش‌نیاز: M01، M02 | زمان تقریبی: ۶ ساعت درس نظری + ۱ تا ۲ ساعت برای هر نرم‌افزار

## چرا این ماژول؟

هیچ روش آماری نمی‌تواند داده‌ای را که بد جمع شده نجات دهد. اینکه **چه کسانی** وارد مطالعه شده‌اند (نمونه‌گیری) و **چطور** داده جمع شده است (طرح مطالعه)، تعیین می‌کند که نتیجه را به چه کسانی می‌توان تعمیم داد و آیا می‌توان دربارهٔ **علت** حرف زد. این ماژول زبان مشترک آمار و اپیدمیولوژی است و همهٔ ماژول‌های بعدی بر آن بنا می‌شوند.

## هدف‌های یادگیری

در پایان این ماژول می‌توانید:

1. جامعهٔ هدف، جامعهٔ مطالعه، چارچوب نمونه‌گیری، نمونه، پارامتر و آماره را در یک مطالعه تشخیص دهید.
2. روش‌های نمونه‌گیری احتمالی (ساده، سیستماتیک، طبقه‌ای، خوشه‌ای، چندمرحله‌ای) و غیراحتمالی را بشناسید و اجرا کنید.
3. خطای نمونه‌گیری را از سوگیری تشخیص دهید و انواع اصلی سوگیری را نام ببرید.
4. طرح‌های اصلی مطالعه (مقطعی، کوهورت، موردشاهدی، کارآزمایی، آزمایش آزمایشگاهی) و شاخص مناسب هر کدام را بشناسید.
5. چهار توضیح جایگزین برای یک ارتباط (شانس، سوگیری، مخدوش‌گری، علیت معکوس) را بررسی کنید.
6. نمونه‌گیری تصادفی و تخصیص تصادفی بلوکی را در SPSS، Prism، R، Python یا Excel انجام دهید.
