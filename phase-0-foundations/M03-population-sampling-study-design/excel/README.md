## بخش آموزشی

### ایده: برای هر روش یک ستون ۰/۱

مثل SPSS، برای هر روش نمونه‌گیری یک ستون کمکی می‌سازیم (۱ = در نمونه) و با `AVERAGEIFS` میانگین را فقط برای ۱ ها حساب می‌کنیم:

```
=AVERAGEIFS(G2:G601, L2:L601, 1)       ← میانگین sbp در نمونهٔ SRS
=100*AVERAGEIFS(H2:H601, L2:L601, 1)   ← شیوع htn در نمونهٔ SRS (درصد)
```

### توابع کلیدی

| کار | فرمول |
|---|---|
| رتبهٔ u (کوچک‌ترین = ۱) | `=RANK(J2,$J$2:$J$601,1)` |
| رتبهٔ u **درون محله** | `=COUNTIFS($B$2:$B$601,B2,$J$2:$J$601,"<"&J2)+1` |
| باقی‌ماندهٔ تقسیم (سیستماتیک) | `=MOD(A2-7,10)=0` |
| شرط «یکی از چند مقدار» | `=OR(C2=4,C2=15,C2=27)` |
| شمارهٔ بلوک ۴ تایی | `=ROUNDUP(A2/4,0)` |

`COUNTIFS(...,"<"&J2)+1` یعنی «چند نفر در همین محله u کوچک‌تری دارند، به‌اضافهٔ یک» = رتبه درون محله. این ترفند در همهٔ نسخه‌های Excel کار می‌کند.

> **نکتهٔ سازگاری:** `RANK.EQ` در Excel 2010 به بعد هست، ولی اگر فایل در نسخهٔ قدیمی‌تر یا برنامهٔ دیگری باز شود ممکن است `#NAME?` بدهد؛ `RANK` در همه‌جا کار می‌کند.

### نمونه‌گیری واقعی در Excel

`=RAND()` در هر سطر یک عدد تصادفی می‌سازد، ولی **با هر تغییر در برگه دوباره عوض می‌شود**. پس:
1. ستون RAND را بسازید.
2. آن را کپی و با `Paste Special > Values` روی خودش بچسبانید تا ثابت شود.
3. حالا بر اساس آن مرتب کنید و n سطر اول را بردارید.
Excel بذر قابل‌تنظیم ندارد؛ پس فایل حاوی اعداد ثابت‌شده را نگه دارید (همان کاری که ما با ستون `u` کرده‌ایم).

### فیلتر برای دیدن نمونه

یک خانه از داده را انتخاب کنید ← `Data > Filter` ← در ستون `in_srs` فقط **1** را تیک بزنید. نوار وضعیت پایین شمار سطرهای دیده‌شده را نشان می‌دهد.

### حل تمرین‌ها

همهٔ فرمول‌ها در فایل حل: ستون‌های K تا R برگهٔ `frame`، ستون‌های C تا E برگهٔ `trial` و برگهٔ `solutions`.

<details>
<summary><b>حل ع۱</b></summary>

```
=AVERAGE(G2:G601)                     → 129.88
=100*AVERAGE(H2:H601)                 → 27.50
=100*AVERAGEIF(B2:B601,1,H2:H601)     → 38.00   (محلهٔ ۱؛ برای ۲ تا ۴ هم همین)
```

</details>

<details>
<summary><b>حل ع۲</b></summary>

```
K2: =RANK(J2,$J$2:$J$601,1)           (رتبهٔ u)
L2: =IF(K2<=60,1,0)                   (in_srs)
=AVERAGEIFS(G2:G601,L2:L601,1)        → 133.12
=100*AVERAGEIFS(H2:H601,L2:L601,1)    → 33.33
```
۵ نفر اول: بر اساس K مرتب کنید (یا Filter) ← 552، 542، 273، 104، 361.

</details>

<details>
<summary><b>حل ع۳</b></summary>

```
M2: =IF(MOD(A2-7,10)=0,1,0)
→ میانگین 131.70، شیوع 31.67
```

</details>

<summary><b>حل ع۴</b></summary>

```

O2: =ROUND(COUNTIF($B$2:$B$601,B2)/600*60,0)           (سهم محله: 20/16/14/10)
```

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| نمونه با هر کلیک عوض می‌شود | `RAND()` فرار است | Paste Values |
| رتبه‌ها برعکس | آرگومان آخر `RANK` صفر است | `1` = صعودی |
| `#NAME?` | تابع جدید در نسخهٔ قدیمی | `RANK` به‌جای `RANK.EQ` |
| فیلتر فقط بخشی از داده را می‌گیرد | سطر خالی وسط داده | سطرهای خالی را حذف کنید |
