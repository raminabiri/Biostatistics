# ماژول M04 — آماده‌سازی و پاک‌سازی داده

**فاز ۰ (پایه)** | پیش‌نیاز: M01، M02 | زمان تقریبی: ۴ ساعت درس نظری + ۲ تا ۳ ساعت برای هر نرم‌افزار

## چرا این ماژول؟

در پژوهش واقعی، بیشترین زمان کار با داده صرف **آماده‌سازی** آن می‌شود، نه تحلیل. خطای کوچکی که در این مرحله دیده نشود (یک فشار ۱۴۵۰، یک بیمار تکراری، قدی که به متر وارد شده) می‌تواند کل نتیجه را خراب کند. این ماژول یک روش منظم و **مستند** برای یافتن و اصلاح این خطاها، ساختن متغیرهای جدید و ترکیب فایل‌ها آموزش می‌دهد.

## هدف‌های یادگیری

در پایان این ماژول می‌توانید:

1. گردش کار تکرارپذیر پاک‌سازی (دادهٔ خام دست‌نخورده، کد، دفترچهٔ پاک‌سازی) را اجرا کنید.
2. خطاهای رایج (تکرار، کدهای ناهمسان، خارج از بازه، ناسازگاری منطقی، تاریخ‌های غیرممکن) را با روش «غربال ← تشخیص ← ویرایش» پیدا و اصلاح کنید.
3. متغیر بازکدگذاری‌شده و محاسباتی (سن از تاریخ، BMI، گروه سنی) بسازید.
4. فایل‌ها را ادغام (Merge)، الحاق (Append) و تجمیع (Aggregate) کنید.
5. همهٔ این‌ها را در SPSS، R، Python یا Excel انجام دهید (Prism در این ماژول نقش محدودی دارد).
