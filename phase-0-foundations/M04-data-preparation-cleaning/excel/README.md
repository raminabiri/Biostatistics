## اصل کار در Excel: داده را بازنویسی نکنید، ستون کمکی بسازید

در Excel وسوسهٔ «درست کردن مستقیم خانه» زیاد است، ولی آن کار دادهٔ خام را از بین می‌برد و قابل‌ردیابی نیست (درس ۴.۱). روش این ماژول: **برای هر قاعده یک ستون فرمولی** کنار دادهٔ خام. ستون‌های اصلی دست نمی‌خورند و هر تصمیم با یک فرمول دیده می‌شود. دفترچهٔ پاک‌سازی عملاً همین ستون‌هاست.

| ستون | قاعده | فرمول (سطر ۲) |
|---|---|---|
| M `key` | کلید کل سطر | `=A2&"\|"&B2&"\|"&...&"\|"&L2` |
| N `exact_dup` | P1 | `=IF(COUNTIF(M$2:M2,M2)>1,1,0)` |
| O `key_dup` | P2 | `=IF(AND(N2=0,COUNTIFS(B$2:B$43,B2,N$2:N$43,0,A$2:A$43,"<"&A2)>0),1,0)` |
| P `keep` | P1+P2 | `=IF(N2+O2=0,1,0)` |
| Q `sex_c` | P3 | `=UPPER(LEFT(TRIM(C2),1))` |
| R `smoker_c` | P4 | `=IF(UPPER(LEFT(TRIM(J2),1))="Y","yes",IF(UPPER(LEFT(TRIM(J2),1))="N","no",""))` |
| S `height_c` | P5 | `=IF(F2<3,F2*100,IF(OR(F2<120,F2>220),"",F2))` |
| T `weight_c` | P6 | `=IF(OR(G2<30,G2>250),"",G2)` |
| U، V | P7 | `=IF(OR(H2=-99,H2<70,H2>260),"",H2)` و مشابه برای dbp |
| W `bp_incons` | P8 | `=IF(AND(U2<>"",V2<>""),IF(V2>=U2,1,0),0)` |
| X، Y | P8 | `=IF(W2=1,"",U2)` |
| Z `preg_c` | P9 | `=IF(Q2="M","",K2)` |
| AA `dob_c` | P10 | `=IF(D2>E2,"",D2)` |
| AB `age` | P11 | `=IF(AA2="","",DATEDIF(AA2,E2,"y"))` |
| AC `in_analysis` | P11 | `=IF(AND(P2=1,OR(AB2="",AB2>=18)),1,0)` |
| AD `bmi` | محاسباتی | `=IF(OR(S2="",T2=""),"",T2/(S2/100)^2)` |
| AE `age_group` | محاسباتی | `=IF(AB2="","",IF(AB2<40,1,IF(AB2<60,2,3)))` |
| AF `n_tests` | تجمیع | `=COUNTIF(labs!$A$2:$A$84,B2)` |
| AG `mean_ldl` | تجمیع | `=IF(AF2=0,"",AVERAGEIF(labs!$A$2:$A$84,B2,labs!$C$2:$C$84))` |

**نکته‌ها:**
- `""` (متن خالی) نقش «گمشده» را بازی می‌کند؛ `AVERAGE`، `AVERAGEIFS` و `SUMIFS` آن را نادیده می‌گیرند.
- `DATEDIF(از, تا, "y")` تعداد **سال کامل** است (درس ۴.۳). این تابع در منوی توابع Excel دیده نمی‌شود، ولی کار می‌کند.
- گروه سنی را عددی (۱، ۲، ۳) گذاشته‌ایم، چون `COUNTIFS(...,"<40")` متن «<40» را **عملگر** «کمتر از ۴۰» می‌خواند، نه برچسب!
- برای شمارش مقادیر یکتا: `=SUMPRODUCT(1/COUNTIF(B2:B43,B2:B43))`.

### روش‌های منویی (مکمل فرمول‌ها)

| کار | منو |
|---|---|
| دیدن تکرارها | `Home > Conditional Formatting > Highlight Cells Rules > Duplicate Values` روی ستون `pid` |
| حذف تکرار (روی **کپی**!) | `Data > Remove Duplicates` |
| پاک‌سازی تکرارپذیر | **Power Query**: `Data > From Table/Range` ← `Transform > Format > Trim / UPPERCASE`، `Replace Values`، `Remove Duplicates` ← هر مرحله در **Applied Steps** ثبت و قابل تکرار است |
| ادغام | Power Query: `Home > Merge Queries` (Join Kind: **Left Outer**) |
| الحاق | Power Query: `Home > Append Queries` |
| تجمیع | PivotTable (`pid` در Rows، `ldl` در Values با Average و Count) یا Power Query: `Group By` |

Power Query در Excel نزدیک‌ترین ابزار به «اسکریپت» است: Applied Steps همان دفترچهٔ پاک‌سازی است و با `Refresh` روی دادهٔ جدید دوباره اجرا می‌شود.

### حل تمرین‌ها

<details>
<summary><b>حل ع۱</b></summary>

```
=COUNTA(raw!B2:B43)                               → 42
=SUMPRODUCT(1/COUNTIF(raw!B2:B43,raw!B2:B43))     → 40
=SUM(raw!N2:N43)                                  → 1   (تکرار کامل)
=SUM(raw!O2:O43)                                  → 1   (تکرار کلید)
```
شکل‌های نوشتاری: **دام Excel!** `COUNTIF`، PivotTable و Remove Duplicates حروف بزرگ و کوچک را **یکی** می‌دانند (`F` = `f`، `Male` = `male`) ولی فاصله را نه. پس PivotTable روی `sex` فقط **۷** ردیف نشان می‌دهد (`M`، `F`، `F `، ` m`، `M `، `Male`، `Female`)، در حالی که R، Python و SPSS **۱۱** شکل می‌شمارند. برای دیدن تفاوت حروف در Excel باید از `EXACT` استفاده کرد (مثلاً `=EXACT(C2,"F")`). این تفاوت روی نتیجهٔ پاک‌سازی اثری ندارد، چون قاعدهٔ P3 به‌هرحال همه را به حرف بزرگ تبدیل می‌کند.

</details>

<summary><b>حل ع۶</b></summary>

ستون‌های AF و AG «تجمیع + ادغام» را با هم انجام می‌دهند: برای هر بیمار، `COUNTIF` و `AVERAGEIF` از برگهٔ `labs`.
```
=COUNTIFS(raw!AC2:AC43,1,raw!AF2:AF43,0)            → 5    (بدون آزمایش)
=AVERAGEIFS(raw!AG2:AG43,raw!AC2:AC43,1)            → 120.58
=COUNTIFS(raw!AC2:AC43,1,raw!AF2:AF43,2)            → 12   (1: 5، 3: 17)
```
بی‌جفت‌ها: ستون کمکی در `labs`: `E2: =IF(COUNTIFS(raw!$B$2:$B$43,A2,raw!$AC$2:$AC$43,1)=0,1,0)` ← سطرهای pid **3** و **99**.

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| Remove Duplicates دادهٔ خام را تغییر داد | روی خود داده اجرا شد | همیشه روی کپی، یا Power Query |
| `TRIM` فاصلهٔ پنهان را حذف نکرد | نویسهٔ «فاصلهٔ نشکن» (CHAR 160) از وب یا Word | `=TRIM(SUBSTITUTE(C2,CHAR(160)," "))` |
| `COUNTIFS(...,"<40")` عدد عجیب داد | «<40» عملگر خوانده شد | برچسب عددی یا `"=<40"` |
| تاریخ‌ها متن ماندند | تنظیمات منطقه‌ای | Power Query: نوع ستون Date با Locale = English (United States) |
