# کدبوک و پروتکل پاک‌سازی ماژول M04

داده‌ها ساختگی‌اند و **عمداً پر از خطا** ساخته شده‌اند تا پاک‌سازی را تمرین کنید. **فایل‌های خام را هرگز ویرایش نکنید**؛ همهٔ تغییرات با کد/Syntax/فرمول روی یک نسخهٔ کاری انجام شود (درس ۴.۱).

## فایل `M04_registry_raw.csv` — ثبت بیماران درمانگاه قلب و متابولیسم (مرکز ۱)

| متغیر | شرح | واحد / کد **درست** | بازهٔ مجاز (پروتکل) |
|---|---|---|---|
| `entry_no` | شمارهٔ ردیف ورود داده (ترتیب ثبت در سامانه) | عدد صحیح | — |
| `pid` | شناسهٔ بیمار (باید یکتا باشد) | عدد صحیح | — |
| `sex` | جنس | `F` = زن، `M` = مرد | — |
| `dob` | تاریخ تولد | YYYY-MM-DD (میلادی) | پیش از تاریخ ویزیت |
| `visit_date` | تاریخ ویزیت | YYYY-MM-DD (میلادی) | — |
| `height_cm` | قد | سانتی‌متر | 120 تا 220 |
| `weight_kg` | وزن | کیلوگرم | 30 تا 250 |
| `sbp` | فشار سیستولی | mmHg | 70 تا 260؛ ‎-99 = اندازه‌گیری نشد |
| `dbp` | فشار دیاستولی | mmHg | 40 تا 150؛ باید کمتر از sbp باشد |
| `smoker` | سیگاری فعلی | `yes` / `no`؛ خالی = نامعلوم | — |
| `pregnant` | باردار (فقط زنان) | `yes` / `no`؛ برای مردان «کاربرد ندارد» | — |
| `hba1c` | هموگلوبین A1c | % | خالی = اندازه‌گیری نشد |

**معیار ورود مطالعه:** سن ۱۸ سال یا بیشتر در تاریخ ویزیت.

هر سطر **یک آزمایش** است؛ هر بیمار ممکن است ۰ تا چند آزمایش داشته باشد (رابطهٔ یک‌به‌چند با ثبت بیماران).

| متغیر | شرح | واحد |
|---|---|---|
| `pid` | شناسهٔ بیمار (کلید پیوند با ثبت بیماران) | — |
| `test_date` | تاریخ آزمایش | YYYY-MM-DD |
| `ldl` | LDL کلسترول | mg/dL |
| `hdl` | HDL کلسترول | mg/dL |

## فایل `M04_site2.csv` — ثبت بیماران مرکز ۲

همان ستون‌ها و کدهای ثبت مرکز ۱؛ این فایل **پاک** است و باید به دادهٔ پاک‌شدهٔ مرکز ۱ **الحاق** شود (درس ۴.۴).

## پروتکل پاک‌سازی (همهٔ مسیرهای نرم‌افزاری دقیقاً همین را اجرا می‌کنند)

| قاعده | کار |
|---|---|
| **P1** | سطرهای **کاملاً تکراری** را حذف کنید (یکی را نگه دارید). |
| **P2** | اگر یک `pid` با مقادیر **متفاوت** دو بار آمده، سطری را نگه دارید که `entry_no` **کوچک‌تری** دارد (ورود اول، که با پروندهٔ کاغذی تطبیق داده شده). |
| **P3** | `sex`: فاصله‌های اضافه را حذف کنید، اولین حرف را بزرگ کنید ← `F` یا `M`. |
| **P4** | `smoker`: اولین حرف بزرگ‌شده `Y` ← `yes`؛ `N` ← `no`؛ خالی ← گمشده. |
| **P5** | `height_cm` کمتر از ۳ ← × ۱۰۰ (به متر وارد شده). سپس قد خارج از ۱۲۰–۲۲۰ ← گمشده. |
| **P6** | وزن خارج از ۳۰–۲۵۰ ← گمشده. |
| **P7** | `sbp` = ‎-99 ← گمشده؛ sbp خارج از ۷۰–۲۶۰ یا dbp خارج از ۴۰–۱۵۰ ← گمشده. |
| **P8** | اگر dbp ≥ sbp ← **هر دو** گمشده (نمی‌دانیم کدام اشتباه است). |
| **P9** | برای مردان، `pregnant` ← گمشده (کاربرد ندارد). |
| **P10** | اگر `dob` بعد از `visit_date` باشد ← `dob` گمشده. |
| **P11** | سن = **سال کامل** بین `dob` و `visit_date`. بیماران با سن **کمتر از ۱۸** از «دادهٔ تحلیل» خارج می‌شوند (کسانی که سنشان نامعلوم است می‌مانند و علامت‌گذاری می‌شوند). |

**متغیرهای محاسباتی:** `age` (P11)، `bmi` = وزن ÷ (قد/۱۰۰)²، `age_group`: کمتر از ۴۰ / ۴۰ تا ۵۹ / ۶۰ و بیشتر.
